업무통합프로그램

투윈원솔루션 계약 병원용 인사·근무 프로그램 — 현재 버전 1.3.1 (2026-11-06)

다운로드

설치 파일 받기 (zip, 약 22MB) 팀장 안내 PDF

병원 PC(윈도우) 한 대에만 설치합니다. 직원은 설치 없이 원내 와이파이로 폰에서 접속합니다.

설치 (3분)

  1. 받은 zip을 압축 해제 → install.bat을 관리자 권한으로 실행.
  2. 바탕화면 바로가기 업무통합프로그램으로 실행 → 처음 화면에서 병원명·관리자 계정을 만듭니다.
  3. 설정 → 근무형태에서 병원에 맞는 형태를 고릅니다 (주5일 / 주6일·주1회 휴무 / 주6일·법정연차). 이어서 부서·직급·근무유형·병원 로고·도장.
  4. 직원 명부 입력(엑셀 가져오기 가능) → 설정 → 접속 주소의 QR을 직원에게 보여 주면 폰에서 가입합니다. 팀장이 승인하면 사용 시작.

데이터는 C:\Twinone\HR\data에만 저장되고 매일 자동 백업됩니다. 설정 → 백업에서 보조 폴더(USB·NAS)를 추가로 지정할 수 있습니다.

팀장이 하는 일

언제무엇을
매주근무표 주간 보기에서 특이사항(OFF·연차·야간)만 입력 — 안 적은 평일은 자동으로 근무
매주휴가 신청함 승인 / 보류 / 반려 (2단계 결재면 원장 최종 승인) · 식사발주표로 업체 주문
매달월별 근무 결산 → 엑셀·인쇄 (근무일·야간·연장·휴무·연차·식대·급여) · 식사 월별 결산
매년 1월연차 → 올해 연차 제안(법정 기준) 확인 후 부여
수시공지(공통·부서별) · 병원일정 · 익명 건의함 답변 · 관리자 알림 확인

직원이 하는 일 (폰)

  • 가입 신청(서명 포함) → 승인 후 휴가 신청(연차계획서 자동 작성) · 식사 선택(날짜별) · 야간·연장 기록 · 내 근무 확인 · 익명 건의
  • 물리치료사는 내 예약에서 환자 예약 관리
  • 앱 안 사용설명서 메뉴에 그림과 함께 쉽게 설명되어 있습니다.

업데이트

  • 새 버전이 나오면 프로그램이 하루 1회 확인하고, 자동 업데이트(기본 켬)면 새벽 2~5시에 혼자 적용합니다 (백업 후 교체, 실패 시 자동 복구).
  • 바로 적용하려면 설정 → 업데이트 → 업데이트 적용.
  • 인터넷이 안 되는 PC는 위 설치 파일을 USB로 옮겨 설정 → 업데이트에서 zip 선택.
